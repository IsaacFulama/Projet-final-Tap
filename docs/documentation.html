DOCUMENTATION RAPIDE

Bien démarrer
avec TAP.

TAP fonctionne avec une base MySQL/MariaDB, généralement fournie par XAMPP. L’exécutable Windows et les documents d’installation sont disponibles dans chaque GitHub Release.

Enregistrements et filtres

Ouvrez Enregistrements dans la barre latérale. La page dédiée propose des filtres combinables par nom, mois, statut, type de souscription et devise. Double-cliquez sur une ligne pour ouvrir l’historique ; le clic droit conserve les actions de modification, paiement, signature, lien et suppression.

Paiements et reçus

Les statuts sont recalculés selon les montants payés : En règle, Litigieux ou En attente. Les rapports PDF peuvent être générés depuis les données filtrées.

Rappels WhatsApp

Le style smart produit un message compact avec le total dû, l’urgence et trois réponses guidées. Si l’API WhatsApp n’est pas configurée, TAP ouvre WhatsApp Web avec le message prérempli.

"overdue_reminders": { "enabled": true, "channel": "whatsapp", "fallback": "whatsapp_web", "style": "smart" }

Sauvegardes

Au démarrage, TAP vérifie si 14 jours se sont écoulés depuis le dernier export. Une archive SQL ZIP est créée, contrôlée, signée par checksum SHA-256 et conservée selon la rotation configurée.

"database_backup": { "enabled": true, "interval_days": 14, "retention": 10 }

Installation Windows

  1. Démarrez MySQL/MariaDB dans XAMPP.
  2. Téléchargez TAP_Gestion_Loyers.exe depuis la dernière release.
  3. Placez config.json à côté de l’exécutable et renseignez la base.
  4. Lancez l’application et changez le mot de passe initial.
